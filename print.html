Templates

Your own Word (.docx) files. Type the placeholders below where the details should go.

Placeholders you can use in your Word files

Order

{invoiceNo} {orderNo} {date} {status} {payment} {printedOn} {businessName}

Customer

{customerName} {customerPhone} {customerAddress} {customerEmail} {deliveryZone}

Money

{subtotal} {discount} {deliveryCharge} {total} {advancePaid} {due}

These include "Tk". Add Amount for the number only, e.g. {totalAmount} → 1,830. {due} = cash the courier collects.

Items (repeats once per item)

Put {#items} before and {/items} after. In a table, put {#items} in the first cell and {/items} in the last cell of the row.

{no} {name} {code} {qty} {price} {lineTotal} · {itemCount}

Tip: type each placeholder in one go (don't format half of it), including both curly brackets.
